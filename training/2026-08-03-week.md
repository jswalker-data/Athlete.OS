build week — `plan.md`'s original Week 1 target (9.3mi total, 5.6mi long
run) was already shelved for it. Actual volume last week was **6.65
miles** (3.14mi parkrun + 3.51mi long run), with both runs holding their
HR ceilings cleanly and no joint pain.

Per the 10% cap (CLAUDE.md hard rule), this week's cap is the **lower**
of two numbers:
- 10% over last week's actual (6.65mi × 1.10 = **7.3mi**)
- `plan.md`'s own Week 2 prescription (10.3mi total, 6.2mi long run)

**7.3mi is the binding number** — it's well under what `plan.md`'s table
originally called for. That's not overcaution, it's the correct
application of the rule off the real baseline you're actually building
from, not the baseline the table assumed before illness intervened.

That 7.3mi budget doesn't leave room for parkrun (~3.1mi, effectively
fixed) + a 10%-capped long run (~3.86mi) + a third Tuesday easy run
without either shrinking the long run below last week's proven-safe
distance or cutting the parkrun short. Rather than do either, **the
Tuesday reset run stays out one more week** — same call as last week,
for the same reason. It comes back in Week 3 once this week's completed
volume raises the baseline enough to fit the full 3-run template under
the cap honestly.

## Strength sessions — full detail

**Monday — Session A (glute & hip stability), ~25-30min, bodyweight only:**
1. Glute bridge — 3×12, 2s pause at the top. *Squeeze glutes, not lower back.*
2. Single-leg glute bridge — 2×10 each side. *Keep hips level, don't let the free side drop.*
3. Clamshells — 2×15 each side. *Slow, controlled, no rocking the pelvis.*
4. Side-lying leg raises — 2×12 each side. *Leg stays in line with the body.*
5. Standing single-leg balance — 2×30s each side (eyes closed last 10s if easy). *Boring on purpose — builds stability under fatigue.*
6. Side plank — 2×20-30s each side. *Hips lifted, straight line shoulder-to-ankle.*

**Thursday — Session B (quad/patellar control, calf, core), ~25-30min, bodyweight only:**
1. Spanish squat or wall sit — 3×30-40s. *Knees tracking over toes, weight through heels.*
2. Step-downs (low step/stair) — 2×10 each side, slow. *Control the descent — eccentric control protects the knee.*
3. Single-leg calf raise — 3×12 each side. *Full range, pause at the top.*
4. Bird-dog — 2×10 each side. *Opposite arm/leg, keep hips square.*
5. Dead bug — 2×10 each side. *Lower back stays flat throughout.*
6. Standing hip flexor stretch + calf stretch — 30s each side to close out.
