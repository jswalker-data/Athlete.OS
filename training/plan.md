## Why this is a full rewrite, not an edit

The v1 plan (2026-07-20) was built when Josh's longest run was 6mi at Z4 and VO2max had been flat at 57 for a month. Two things have since changed enough to invalidate its core assumptions:

1. **He's ahead of the v1 schedule.** As of Aug 10 the longest run is **8.0mi at flat Z2 (144bpm, no drift)** — v1 didn't have him reaching 8mi until Week 4-5. VO2max ticked to 58, ACWR is now OPTIMAL/PRODUCTIVE (was LOW), and Z2 discipline is genuinely closing.
2. **The guardrails were redesigned** (2026-08-10, with Josh's coaches). The old blanket 10%/week cap is replaced by two separate ceilings — long run ≤10% over the 3-week max, weekly volume ≤30% over the 2-week max. This lets the long run ramp to **~11.5mi (~88% of race distance)** instead of v1's deliberately-capped 9.9mi (76%), which directly attacks the endurance gap gating the 1:42 target.

**Two things also drive the new emphasis:** Josh re-confirmed **1:42:00** as the target (Aug 10), and named **pacing / going out too hot** as his top worry — which is also the #1 failure mode finishers report at this specific race (the mile 10-11 fade). So this plan's spine is **race-pace discipline**, not just aerobic volume.

## Weekly template

**Phase 1 hinge (Week 1, Aug 10-16):** already built — see `training/2026-08-10-week.md`. Consolidate 8mi, race the parkrun as a pacing lab, both strength sessions.

**Phase 2-3 (Weeks 2-5) — one hard quality session per week, pacing-led:**

| Day | Session |
|---|---|
| Mon | Strength (A/B alternating), AM |
| Tue | **Quality** — rotates: race-pace / threshold / (occasional) hill |
| Wed | Rest, or optional easy Z2 shakeout if the week allows |
| Thu | Strength (AM — Thursday-evening hard no) |
| Fri | Rest |
| Sat | Parkrun — **controlled** on weeks with a Tuesday quality session; **raced as an even/negative-split pacing lab** on weeks without one |
| Sun | Long run, Z2, **controlled/negative-split finish** (race-pace segment in later weeks) |

Reasoning: ~3 runs + 2 strength = 5 sessions (Josh's comfortable ceiling), with **one true hard effort per week** (Bakken hard/easy, Seiler ~80/20 by session). The 48-hour rule is protected by never stacking two hard efforts — if Tuesday is quality, Saturday's parkrun is controlled, and vice versa. The long run is Z2 *intensity* (long, not hard), so a controlled parkrun Saturday + long run Sunday is a legitimate back-to-back; a *raced* parkrun only pairs with a deliberately easy/cuttable Sunday long run.

**Quality session menu (all built around the 1:42 target / anti-going-out-too-hot):**
- **Race-pace (the priority):** goal-pace reps @ **7:47/mi**, growing across the block — e.g. 4×0.6mi (Wk2) → 3×1mi (Wk3-4) → 2×1.5mi (Wk5), short jog recovery. Trains pace *calibration* so race morning isn't the first time he feels 7:47/mi under control.
- **Threshold:** 2×10min @ **7:23-7:30/mi** (4:35-4:40/km), 2min jog. Raises the ceiling so goal pace costs less.
- **Hill (occasional, secondary):** 6-8×60-90s hard on the steepest local incline/stairs, easy jog down — targets limiter #4 and the rolling course.
- **Progression / negative-split long run (Phase 2-3):** final 2-3mi of the long run lifted toward goal pace after a controlled first two-thirds — the single most race-specific anti-fade session, directly rehearsing the mile 10-11 discipline the race demands.

**Week 6 (taper, Sep 14-20):** same skeleton, volume down ~35%. Tuesday quality becomes 3-4×0.6mi @ goal race pace (7:47/mi), full recovery — race-specific sharpening in the final fortnight (van den Broek). Parkrun (Sep 19): easy jog only, no effort.

**Week 7 (race week, Sep 21-27):** Mon rest, Tue/Wed short easy shakeouts, no long run, no parkrun effort (Sep 26 is the day before — jog or rest). **Race Sunday 27th.**

## Race-pace & pacing plan (the spine of this build)

Given Josh's top worry and the race's failure mode, pacing gets trained explicitly, not left to race day:
1. **Calibrate 7:47/mi by feel and HR** through the race-pace sessions, so goal pace is a known, repeatable sensation.
2. **Every long run finishes controlled or negative-split** — never fading. This is the direct rehearsal for mile 10-11.
3. **Parkruns run as pacing labs** — even or negative split, "hard but not reckless off the line."
4. **A pre-decided opening-2-miles plan for race day** — by HR, not adrenaline, deliberately a touch conservative to survive the crowd/pacer pull. Locked in `/fuel-and-pace` nearer the race.

## Fueling

Start rehearsing race-day carb intake on long runs from **Week 2-3 onward** (the first runs crossing ~75+ min, ~9mi+): **30-60g carbs/hour** (e.g. a gel every 40-45min). Train the gut before race day (Roche), dose calibrated for a 1:42 half — not ultra-sized. Detailed plan via `/fuel-and-pace` closer to race week.

## Non-negotiable / adaptive rules

1. **Joint pain = stop, no negotiation.** Not soreness — pain. Most relevant as volume and long runs climb.
2. **A missed or cut-short week is recovery, not regression** — named so it doesn't trigger the "wasted week" spiral.
3. **Easy/long means Z2 (124-144bpm)**, held deep into the run, even when the pace looks slow.
4. **The revised volume guardrails, both hard:** long run ≤~10% over the longest run in the last 3 weeks; weekly volume ≤~30% over the higher of the last 2 weeks. Never breach either without saying why first. Flexible week edges (a Monday long run can count for the previous week).
5. **One hard quality effort per week** — never two hard efforts within 48 hours.
6. **Pacing discipline is a training target, not just a race-day hope** — controlled long-run finishes and even-split parkruns count as much as hitting the distance.
7. **Poor sleep/readiness that day → the session downgrades** (quality → easy, easy → rest), decided in the moment.
8. **No parkrun effort the week of the race.**
