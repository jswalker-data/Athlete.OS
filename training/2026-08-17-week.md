## Strength sessions — full detail

**Monday — Session A (glute & hip stability), ~25-30min, bodyweight only:**
1. Glute bridge — 3×12, 2s pause at the top. *Squeeze glutes, not lower back.*
2. Single-leg glute bridge — 2×10 each side. *Keep hips level, don't let the free side drop.*
3. Clamshells — 2×15 each side. *Slow, controlled, no rocking the pelvis.*
4. Side-lying leg raises — 2×12 each side. *Leg stays in line with the body.*
5. Standing single-leg balance — 2×30s each side (eyes closed last 10s if easy). *Boring on purpose — builds stability under fatigue.*
6. Side plank — 2×20-30s each side. *Hips lifted, straight line shoulder-to-ankle.*

**Thursday — Session B (quad/patellar control, calf, core), ~25-30min, bodyweight only:**
1. Spanish squat or wall sit — 3×30-40s. *Knees tracking over toes, weight through heels.*
2. Step-downs (low step/stair) — 2×10 each side, slow. *Control the descent — eccentric control protects the knee.*
3. Single-leg calf raise — 3×12 each side. *Full range, pause at the top.*
4. Bird-dog — 2×10 each side. *Opposite arm/leg, keep hips square.*
5. Dead bug — 2×10 each side. *Lower back stays flat throughout.*
6. Standing hip flexor stretch + calf stretch — 30s each side to close out.

## Mobility session — full detail

**Wednesday — Mobility/Prehab, ~15min, bodyweight only:**

Distinct from Sessions A/B on purpose — dynamic movement and balance work rather than loaded strength, so it adds a knee/hip touchpoint without adding real fatigue between Tuesday's quality and Thursday's strength day.

1. Standing hip circles — 10 each direction, each leg. *Big, controlled circles — this is a warm-up for the hip joint, not a stretch.*
2. Leg swings (front-to-back + side-to-side, holding a wall/chair) — 10 each direction, each leg. *Controlled range, not momentum — stop before it gets loose/kicky.*
3. World's Greatest Stretch (lunge + rotation) — 3 each side. *Reach the elbow to the instep, then rotate and reach the same-side arm to the ceiling — opens hip and thoracic spine together.*
4. Standing single-leg balance — 2×30s each side (close eyes for the last 10s if easy). *Boring on purpose — this is the stability work that holds up under fatigue late in a run.*
5. Side plank — 2×20-30s each side. *Hips lifted, straight line shoulder-to-ankle.*
6. Standing quad stretch — 30s each side. *Knee pointing straight down, don't pull the foot toward the glute if that pinches.*
7. Standing hip flexor stretch — 30s each side. *Squeeze the glute on the back leg to deepen it.*
8. Calf stretch (wall or step) — 30s each side, straight-leg then bent-knee. *Straight leg gets the gastrocnemius, bent knee gets the soleus — do both.*
